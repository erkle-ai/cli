# Security

Please report vulnerabilities privately through a
[GitHub security advisory](https://github.com/erkle-ai/cli/security/advisories/new),
not a public issue. Include what you found, how to reproduce it, and the
`@erkle/cli` version.

`erkle init` (from `@erkle/cli`) writes configuration files in your repository and home directory.
Reports about it writing outside those locations, executing anything from a
repository it runs in, or leaking file contents are in scope.
